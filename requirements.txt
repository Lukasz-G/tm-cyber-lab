# Two Windows gotchas on this machine, both already paid for:
#   * PYTHONIOENCODING=utf-8 is required -- pip's progress bar cannot print the non-Latin-1
#     character in the user's home path under the console's cp1252 codepage, and the install dies
#     with UnicodeEncodeError partway through.
#   * wittgenstein needs SETUPTOOLS_USE_DISTUTILS=stdlib when the venv uses --system-site-packages,
#     or its build fails in _distutils_hack with an AssertionError on core.__file__. Because pip
#     installs a requirements file as a unit, that one failure aborts everything else too -- install
#     it separately if it breaks again.
#
# Pinned loosely on purpose: none of these is load-bearing for a result, and the
